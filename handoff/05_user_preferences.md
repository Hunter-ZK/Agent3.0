# 用户偏好与教学约定

## 1. 教学语言

- 中文为主。
- 专业术语保留英文。
- 用户需要结构化、严格、可执行的工程训练。

## 2. 教学循环

用户偏好：

```text
理论讲解 → 代码演示 → 动手练习 → 检查理解
```

## 3. 用户技术背景

- Python 当前较生疏。
- 曾有较好的 Java 工程基础。
- 正在学习 AI Agent。
- 目标服务于离线数仓开发。
- 当前 SQL 环境偏 DataWorks / MaxCompute。

## 4. 输出偏好

- 不要泛泛讲原则。
- 要明确新增文件、修改文件、删除文件。
- 代码要有足够注释，尤其是属性、参数、函数使用场景。
- 大段文档或多文件源码优先打包，不要在网页里直接贴混乱的 Markdown 源码。
- 复杂迁移要减少重复劳动。
- 每轮最好推进一个完整工程里程碑。

## 5. 近期重要纠偏

用户认为：

- 代码量已经偏大。
- `analysis` 的文本处理不应成为学习重点。
- 现有效果偏基础。
- LLM 应该发挥更大作用。
- 未来目标是 Web 应用，不是 CLI。
- 需要 RAG / 向量库。
- DataAgent 要纳入参考，但不能超出当前能力。

## 6. 后续助手应注意

- 不要继续无节制扩展 CLI。
- 不要继续堆复杂正则和 parser。
- 不要把 LLM 限制成 rule 的附属品。
- 应把当前项目收口为 Engine，再推进 Web + RAG + Agent。
- 需要先出设计，用户确认后再执行。
